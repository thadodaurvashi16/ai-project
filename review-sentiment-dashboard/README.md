# Review Sentiment Dashboard

A machine learning project that predicts whether a customer review is Positive or Negative.

## Technologies

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit
- Jupyter Notebook

## Project Structure

review-sentiment-dashboard/

├── data/
├── images/
├── models/
├── notebooks/
├── app.py
├── README.md
├── requirements.txt
└── .gitignore

## How to Run

Install dependencies:

pip install -r requirements.txt

Run Streamlit:

streamlit run app.py

## Model

The project uses:

- TF-IDF Vectorizer
- Logistic Regression

## Output

The application predicts:

- Positive 😊
